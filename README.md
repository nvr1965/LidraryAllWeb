# LidraryAllWeb — общие блоки для всех проектов

Здесь лежат **оригиналы** общих блоков. Claude знает о них через skills в аккаунте
(Настройки → Capabilities → Skills), поэтому сам подтягивает нужный блок в любом проекте.

| Папка | Что это | Skill в Claude |
|---|---|---|
| `camera-block/` | Камера: фото и видео (React) | `camera-block` |
| `i18n-block/`   | Многоязычность: автоперевод, RTL, флаги, админка языков (React + PHP + PostgreSQL) | `i18n-block` |

В каждой папке:
- файлы кода — эталон, который копируется в проекты;
- `README.md` — коротко, что это;
- `SKILL.md` — инструкция для Claude (ровно то, что загружено в skill).

## Как подключить блок к проекту
1. Открыть проект в Claude (или чат по этому проекту).
2. Написать: «подключи наш блок камеры» / «добавь i18n по нашему стандарту».
3. Claude скопирует код из skill в проект и подскажет, что адаптировать.

Чтобы Claude брал эталон всегда, в инструкции проекта (Project instructions или `CLAUDE.md` в корне проекта) добавить строку:

> Для камеры и переводов используем общие блоки `camera-block` и `i18n-block` из LidraryAllWeb, не писать их заново.

## Как обновить блок
1. Исправить код здесь, в `LidraryAllWeb`.
2. Сказать Claude: «обнови skill camera-block из E:\LidraryAllWeb\camera-block» — он обновит skill (появится карточка «Сохранить»).
3. В проектах, где блок уже стоит: «обнови блок камеры до общей версии». Скопированный код сам не обновляется.

## Как добавить новый блок
1. Создать папку `имя-block/` и положить туда код.
2. Сказать Claude: «сделай skill из E:\LidraryAllWeb\имя-block».
3. Claude напишет `SKILL.md` и предложит сохранить skill.

## Правила
- Ключи и пароли (`secrets.php`, `config.local.php`, `.env`) сюда не кладём — они в `.gitignore`.
- Один блок — одна папка — один skill.
